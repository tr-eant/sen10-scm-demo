# SCM Assignment Project

A static portfolio showcase demonstrating automated Software Configuration Management, CI/CD pipelines, and quality gates using GitHub Actions and GitHub Pages.

## Project Structure
- `index.html`: Main landing page markup.
- `style.css`: Modern responsive styles.
- `script.js`: Interactive counter script.
- `package.json`: Project manifest and npm scripts.
- `eslint.config.js`: ESLint v9 configuration enforcing semicolons.
- `.github/workflows/deploy.yml`: CI/CD pipeline definition.
